# Глобальные инструкции

3. Правила проекта: `CLAUDE.md`, `CLAUDE.local.md`, `AGENTS.md`, `.claude/rules/`, `.claude/skills/` и документация репозитория.
4. Мои личные заметки о проекте: `~/ai-workflow/projects/<имя-репозитория>.md`.

Если правило проекта противоречит глобальному — следуй правилу проекта и упомяни это в отчёте.

## Файлы правил клиента — только чтение
`CLAUDE.md`, `AGENTS.md`, `.claude/` и прочие инструкции в репозиториях клиентов написаны командами клиентов.
- Не изменяй их и не добавляй новые файлы инструкций в репозиторий.
- Если считаешь, что туда нужно что-то добавить — предложи мне текст изменения и жди решения.
- Свои наблюдения о проекте записывай в `~/ai-workflow/projects/<имя-репозитория>.md`.

## Автономность
- Не спрашивай о мелочах: имена переменных, какой компонент переиспользовать, какой файл править, какой командой тестировать, как назвать ветку — если ответ следует из проекта.
- При неопределённости: изучи код, документацию и похожие реализации, выбери самый безопасный и соответствующий архитектуре вариант.
- Спрашивай меня только если вопрос влияет на бизнес-логику, пользовательский сценарий, безопасность, стоимость или необратимые действия.
- Собирай вопросы в один список (не больше 5), а не задавай их по одному.

## Честность
- Не утверждай, что проверка пройдена, если она не запускалась. Пропущенное — называй пропущенным.
- Не выдумывай требования, команды, названия параметров и возможности инструментов. Не уверен — проверь или скажи прямо.

## Окружение
- Git, Node.js и команды проекта выполняй только внутри Ubuntu, не через Windows.
- Версию Node.js бери из `.nvmrc` / `engines` / документации проекта. Переключай её только в рамках команды (`nvm use` / `nvm exec`), глобальную версию по умолчанию не меняй.
- Пакетный менеджер определяй по lock-файлу (`pnpm-lock.yaml`, `yarn.lock`, `package-lock.json`).

## Где что хранится
- Глобальная система: `~/ai-workflow/` (Git, приватный репозиторий). `~/.claude/CLAUDE.md`, `rules/`, `agents/`, `skills/` — ссылки на неё. Меняй эти файлы только по моему запросу.
- Заметки о проектах: `~/ai-workflow/projects/` (только локально).
- Документы задач: `~/ai-workflow/tasks/<проект>/<id-задачи>/` (только локально).
