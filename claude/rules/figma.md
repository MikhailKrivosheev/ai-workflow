# Работа с макетами Figma

Общие правила для всех проектов. Особенности конкретного макета (id узлов, соответствие стилей) — в карточке проекта `~/ai-workflow/projects/<репозиторий>.md`.

## Какой макет актуален
Ссылки на Figma в задаче могут вести в старый клиентский файл. Ссылки, которые я даю в сообщении, важнее ссылки из задачи.

## Выводы о макете — по совокупности источников
Вывод «в макете есть / нет X», «X выглядит так» делай, сопоставив несколько источников:
- дерево слоёв (`get_metadata`) — структура, вложенность, размеры;
- скриншот узла (`get_screenshot`) — что реально видно;
- названия слоёв и фреймов;
- свойства, стили и переменные (`get_design_context`, `get_variable_defs`);
- видимость слоёв, варианты компонентов, состояния;
- сравнение десктопной и мобильной версий.

Ни один источник сам по себе не решающий. Источники расходятся (слой есть в дереве, но не виден на скриншоте; название фрейма не совпадает с содержимым) — выясни причину: скрытый слой, вариант, устаревшая подпись. Не удалось — это вопрос мне, а не вывод.
В spec, плане и отчёте указывай, на чём основан вывод.

## Большие макеты
- Работай по блокам: сначала `get_metadata` верхнего уровня, потом — по узлам отдельных блоков.
- Ответ MCP ограничен ~25 тыс. токенов: крупные ответы сохраняй в файл в папке задачи и читай частями.
- Проверяй и десктоп, и мобильную версию, если обе есть в макете.

## Подключение
- Нужно запущенное приложение Figma с открытым файлом (локальный сервер `127.0.0.1:3845`).
- Сервер отвечает, а инструменты MCP в сессии не появились — можно вызвать его напрямую JSON-RPC через `curl` (`initialize` → `tools/call`); скриншоты приходят в base64.

## Картинки и фото — только через REST API Figma
Локальный MCP отдаёт картинки уменьшенными (до 1024 по ширине), а скриншот узла — в размере макета, без масштаба. Для вёрстки их не использовать и размер исходника по ним не определять.
- Токен: `~/.config/figma/token` (заголовок `X-Figma-Token: $(cat ~/.config/figma/token)`), в ответы и логи не выводить. Нет токена или 403/404 на файл — попросить токен аккаунта с доступом к файлу (`request_secret`).
- Ключ файла — из ссылки `figma.com/design/<ключ>/…`, узел `1-23` из ссылки → `1:23`.
- Оригинал фото: `GET https://api.figma.com/v1/files/<ключ>/nodes?ids=<узел>` → `imageRef` в `fills` слоя → `GET /v1/files/<ключ>/images` → ссылка на исходник по `imageRef`. Размер исходника — по скачанному файлу.
- Составная графика или слой с обрезкой/эффектами: `GET /v1/images/<ключ>?ids=<узел>&scale=<3|4>&format=png` (масштаб — по правилу «3–4x от показа, не больше исходника» из `learned.md`).
- Ссылки из ответа API временные — скачивать сразу, в папку задачи.
